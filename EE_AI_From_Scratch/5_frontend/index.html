3. How It Was Built (your learning path)

  • Step 1 Generated 900 waveforms (300 each type) as training data — like building a signal library
  • Step 2 Built a single neuron: weighted sum + ReLU activation — like an op-amp + half-wave rectifier
  • Step 3 Stacked neurons into 3 layers (50→64→32→3) — like cascaded filter stages

3. How It Was Built

  • Step 1 900 noisy waveforms generated as labeled training data
  • Step 2 Single neuron: weighted sum + ReLU = summing amp + half-wave rectifier
  • Step 3 Network: 50→64→32→3 (cascaded filter stages)
  • Step 4 500 epochs backprop: auto-tuned 6,531 weights to ~99% accuracy
  • Step 5 Flask REST API + this HTML page = full-stack AI
